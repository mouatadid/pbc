# Utility functions used by data and models

## Contents

- data_io.py: data input and output utility functions (e.g., load_data and save_to_zarr)
- file_io.py: file input and output utility functions (e.g., set_file_permissions, make_directories with shared permissions, and symlink)
- logging.py: logging utility functions (e.g., setup_logging)
- notebook.py: utility functions supporting jupyter notebooks
- timing.py: timing utility functions (e.g., tic and toc)
